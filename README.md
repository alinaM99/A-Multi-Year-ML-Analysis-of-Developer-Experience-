# A-Multi-Year-ML-Analysis-of-Developer-Experience-
End-to-end ML analysis of developer experience using 3 years of Stack Overflow survey data (2022–2025). Built with Python, PyTorch, LightGBM, SHAP and Gaussian Mixture Models to predict DevX, uncover key influencing factors and developer profiles, and explore how AI-assisted development is reshaping the developer experience.
